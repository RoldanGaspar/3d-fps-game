# 3D GAME FPS

A first-person shooter game built with **Unity 6** (6000.3.6f1) using the **Universal Render Pipeline (URP)**.

## 🎮 Project Overview

| Detail           | Value                         |
|------------------|-------------------------------|
| Engine           | Unity 6 (6000.3.6f1)         |
| Render Pipeline  | URP 17.3.0                   |
| Input System     | New Input System 1.18.0      |
| Version          | 0.1.0                        |
| Company          | DefaultCompany                |

## 📁 Project Structure

```
3D GAME FPS/
├── Assets/
│   ├── Scenes/          # Game scenes (SampleScene.unity)
│   ├── Settings/        # URP & rendering settings (PC + Mobile)
│   └── TutorialInfo/    # Unity template readme assets
├── Packages/            # Unity Package Manager dependencies
├── ProjectSettings/     # Editor & project configuration
└── UserSettings/        # Local user preferences (not committed)
```

## 🚀 Getting Started

### Prerequisites

- **Unity 6** (version 6000.3.6f1 or compatible)
- Unity Hub installed

### Setup

1. Clone or download this repository.
2. Open **Unity Hub** → **Add** → select the `3D GAME FPS/` project folder.
3. Unity will import all assets and packages automatically.
4. Open `Assets/Scenes/SampleScene.unity` to start working.
